Análise de Algoritmos

Aplicação dos conteúdos da disciplina de Análise de Algoritmos ao projeto BioIoT.

Objetivo do módulo

Esta seção apresenta experimentos de busca, ordenação, complexidade computacional, recursividade, intratabilidade e precisão numérica.

O módulo utiliza medições reais registradas pelo ESP32 para demonstrar algoritmos de busca, ordenação e análise estatística. Também apresenta experimentos acadêmicos com dados simulados para estudar complexidade temporal, espacial, recursividade, intratabilidade e precisão numérica. As análises não modificam o histórico armazenado no banco de dados.
